## 🎯 Objective

Build a complete Insertion Sort application using functions while sorting a user-defined array, validating the array size, and tracking comparisons and shifts.

## 📁 Files

Insertion_Sort_Project.c

## 📝 Notes

Implemented the Insertion Sort algorithm using functions. Allowed the user to create a custom array. Repeatedly requested the array size until a valid positive value was entered. Sorted the array in ascending order using Insertion Sort. Used a temporary key value while shifting larger elements to the right. Counted the total number of comparisons and shifts performed during sorting. Displayed the sorted array together with comparison and shift counts. Practiced designing a modular program without using global variables.
