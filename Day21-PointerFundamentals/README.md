## 🎯 Objective

Build a menu-driven Game Stats Manager while practicing the fundamentals of pointers in C.

## 📁 Files

Pointer_Fundamentals_Project.c

## 📝 Notes

Learned how variables are stored in memory and how pointers can store and access memory addresses. Practiced using the address operator (&) and dereference operator (*) to read and modify values indirectly. Reassigned a single pointer to different integer variables during program execution. Used NULL to represent a pointer with no valid target and reviewed the risks of uninitialized and invalid pointers.

Built a menu-driven Game Stats Manager where health, armor, and coin values are modified through a single integer pointer. Practiced combining pointers with functions, loops, conditional statements, and user input while keeping all variables local and avoiding global variables.
