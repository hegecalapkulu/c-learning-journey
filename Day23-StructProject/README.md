## 🎯 Objective

Build a menu-driven Library Book System while practicing structs with pointers and modifying struct fields through pointer parameters.

## 📁 Files

library_book_system.c

## 📝 Notes

Practiced defining structs and creating struct variables, accessing fields with the dot operator, and grouping related data into a single struct instead of using parallel arrays. Learned where a struct type definition needs to live in the file so every function can see it.

Built a menu-driven Library Book System where an array of Book structs is passed to functions through pointers. Implemented searching for a book by name, borrowing and returning books, listing available books, input validation, and program flow until the user chooses to exit.

Practiced combining structs with pointers using the arrow operator, functions, loops, conditional statements, switch statements, and user input while keeping all variables local and avoiding global variables.
