## 🎯 Objective

Build a complete Selection Sort application using functions while sorting a user-defined array and tracking comparisons and swaps.

## 📝 Notes

Implemented the Selection Sort algorithm using functions. Allowed the user to create a custom array. Validated the array size before creating the array. Sorted the array in ascending order using Selection Sort. Counted the total number of comparisons and swaps performed during sorting. Displayed the sorted array together with comparison and swap counts. Practiced designing a modular program without using global variables.
