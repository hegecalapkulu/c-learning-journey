## 🎯 Objective

Build a menu-driven Bank Account Manager while practicing pointers with functions and modifying variables through pointer parameters.

## 📁 Files

pointers_bank_account_manager.c

## 📝 Notes

Practiced passing the addresses of variables to functions and modifying their values through pointer parameters. Used multiple pointer parameters in the same function and applied pointers to real program logic instead of only simple examples.

Built a menu-driven Bank Account Manager where balance and savings values are modified through pointer parameters. Implemented deposit, withdrawal, transfers between accounts, balance display, input validation, and program flow until the user chooses to exit.

Practiced combining pointers with functions, loops, conditional statements, switch statements, and user input while keeping all variables local and avoiding global variables.
