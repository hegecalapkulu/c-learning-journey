## 🎯 Objective

Build a complete Bubble Sort application using functions while sorting a user-defined array and optimizing the algorithm with the `swapped` flag.

## 📁 Files

Bubble_Sort_Project.c

## 📝 Notes

Implemented the Bubble Sort algorithm using functions. Allowed the user to create a custom array. Validated the array size before creating the array. Sorted the array in ascending order using Bubble Sort. Optimized the algorithm using the `swapped` flag to avoid unnecessary passes. Counted the number of comparisons and swaps performed during sorting. Displayed the sorted array along with comparison and swap counts. Practiced designing a modular program without using global variables.
